# RMPM Web Demo

架空の「福岡未来市 市長選挙」を舞台に、公約と公開資料から確認可能な活動との関係をたどるコンテスト用Webデモです。候補者の採点・ランキング・達成率表示は行いません。

## 1. 作成したファイル一覧

- `index.html` — Vite SPAのHTMLエントリとページ・SNS共有メタデータ
- `src/main.jsx` — Reactの起動エントリ
- `src/App.jsx` — トップ、候補者詳細、政策比較、方法論、資料モーダルの画面と操作
- `src/index.css` — 全画面のレイアウト、配色、レスポンシブCSS
- `src/components/RmpmMap.jsx` — RechartsによるRMPM ScatterChart
- `src/data/mockData.js` — 架空候補者3人、4政策、活動、説明、一次資料データ
- `public/og.png` — SNS共有用プレビュー画像
- `vite.config.js` — 通常のReact + Vite SPA設定
- `package.json` / `pnpm-lock.yaml` — 依存関係とコマンド

## 2. 起動方法

Node.js 22.13以上を使用してください。

```bash
npm install
npm run dev
```

起動後、`http://localhost:3000` を開きます。静的なプロダクションビルドは `npm run build` で、成果物は `dist/` に生成されます。

### Vercel設定

- Framework Preset: `Vite`（または `Other`）
- Build Command: `npm run build`
- Output Directory: `dist`

SSR、React Server Components、Next.js、Vinextは使用していません。

## 3. デモを見る順番

1. トップのコピーと「採点しません」の宣言を確認
2. 「田中 未来」を選び、子育て政策の「過去公約 → 活動 → 現在公約 → 説明 → 根拠資料」を確認
3. 「資料を見る」ボタンで架空の一次資料抜粋を確認
4. 政策タブを切り替え、「回答なし」のケースを確認
5. RMPMマップと、その下の非評価に関する注意書きを確認
6. 「政策比較」で同一政策を3候補横並びにして確認
7. 「佐藤 葵」で初回立候補者の表現を確認
8. 「方法論」でAIの限定的な役割とRMPMの前提を確認

## 4. 今後改善すべき点

- 架空データではなく実運用データを扱う場合の、一次資料収集・更新・訂正フロー
- 候補者本人による説明の受付、本人確認、回答履歴の保存
- 活動と公約を関連付ける基準の公開と、第三者レビューの仕組み
- 公開資料に現れない活動があることを、より細かく伝える注記設計
- スクリーンリーダー、キーボード操作、色覚多様性を含むアクセシビリティ監査
- スマートフォンでの比較画面をカード式・スワイプ式に改善
- URLで候補者・政策を直接共有できるルーティング
- 実データの利用規約、個人情報、選挙期間中の運用ルールに関する法務確認

## 注意

登場する候補者、政党、自治体、会議録、予算資料、質問主意書、選挙公報はすべて架空です。RMPMの位置は候補者の優劣、正しさ、誠実さ、公約達成率を示しません。

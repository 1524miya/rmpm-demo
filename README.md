# RMPM Web Demo

完全な架空自治体による「未来市長選挙 2026」を舞台に、公約・公開資料から確認可能な活動・本人説明・取材・根拠資料をつなぐコンテスト用Webデモです。本デモに登場する自治体、候補者、活動記録、資料、メディアはすべて架空です。候補者の採点・ランキング・達成率表示は行いません。

RMPMは **Relative Manifesto-Positioning Map** の略です。確認できない記録を「活動していない」という評価へ変換せず、地域・議会側の情報公開状況も合わせて示します。

## 1. 作成したファイル一覧

- `index.html` — Vite SPAのHTMLエントリとページ・SNS共有メタデータ
- `src/main.jsx` — Reactの起動エントリ
- `src/App.jsx` — トップ、候補者詳細、政策比較、方法論、資料モーダルの画面と操作
- `src/index.css` — 全画面のレイアウト、配色、レスポンシブCSS
- `src/components/RmpmMap.jsx` — RechartsによるRMPM ScatterChart
- `src/data/mockData.js` — 架空選挙、候補者、政策、記録確認状態、役職別確認項目、地域透明性データ
- `public/og.png` — SNS共有用プレビュー画像
- `vite.config.js` — 通常のReact + Vite SPA設定
- `package.json` / `pnpm-lock.yaml` — 依存関係とコマンド

## 2. 起動方法

Node.js 22.13以上を使用してください。

```bash
npm install
npm run dev
```

起動後、`http://localhost:3000` を開きます。静的なプロダクションビルドは `npm run build` で、成果物は `dist/` に生成されます。

### Vercel設定

- Framework Preset: `Vite`（または `Other`）
- Build Command: `npm run build`
- Output Directory: `dist`

SSR、React Server Components、Next.js、Vinextは使用していません。

## 3. デモを見る順番

1. トップのコピーと「採点しません」の宣言を確認
2. 「甲斐 賢人」を選び、子育て政策の「過去公約 → 活動 → 現在公約 → 説明 → 根拠資料」を確認
3. 「資料を見る」ボタンで架空の一次資料抜粋を確認
4. 政策タブを切り替え、「回答なし」のケースを確認
5. 活動欄で「確認済み」「一部のみ公開」「該当記録が未公開」の違いを確認
6. 地域・議会の情報公開状況で、未来市・利名市・若葉野市を項目別に比較
7. RMPM（相対的公約位置地図）と、その下の非評価に関する注意書きを確認
8. 「政策比較」で記録状態と本人説明を含めて3候補を横並びで確認
9. 「強井 明路」で初回立候補者の表現を確認
10. 「方法論」で役職別確認項目、単純な賛否との違い、AIの限定的な役割を確認

## 4. 今後改善すべき点

- 架空データではなく実運用データを扱う場合の、一次資料収集・更新・訂正フロー
- 候補者本人による説明の受付、本人確認、回答履歴の保存
- 活動と公約を関連付ける基準の公開と、第三者レビューの仕組み
- 自治体ごとの議事録公開方式・更新日を継続取得する仕組み
- 記録の未公開・更新遅れ・検索不能を判別する監査履歴
- スクリーンリーダー、キーボード操作、色覚多様性を含むアクセシビリティ監査
- スマートフォンでの比較画面をカード式・スワイプ式に改善
- URLで候補者・政策を直接共有できるルーティング
- 実データの利用規約、個人情報、選挙期間中の運用ルールに関する法務確認

## 注意

登場する候補者、政党、自治体、会議録、予算資料、委員会資料、選挙公報、メディアはすべて架空です。RMPMの位置は候補者の優劣、正しさ、誠実さ、公約達成率を示しません。
